# FINWEB SOLUTION

A static-first international B2B website combining Financial Operations & Accounting with Digital Architecture & Web Development.

## Local run

```powershell
npm run dev
```

The committed application uses local, synthetic adapters and makes no production provider calls. Runtime packages are present. The optional test/lint tool installation was skipped after a peer-dependency conflict, so only scripts backed by installed tools should be treated as verified.

## Routes

- `/`
- `/financial-services`
- `/web-development`
- `/portfolio`
- `/portfolio/[slug]`
- `/about`
- `/contact`
- `/privacy/request`

## Privacy and content

Do not place secrets, personal data, client documents, or unapproved claims in source control. Production analytics, CMS, calendar, uploads, bot protection, and monitoring must remain behind reviewed adapters.
